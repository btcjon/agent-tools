# Public source manifest

This package was independently assembled from the reviewed Jev advisor prototype in the owner's private AI control plane. Only the portable production dependency closure was promoted:

- `src/jev_skill_advisor/{client,exposure,protocol,profile,runtime,service,service_cli,mcp_server,admin_cli}.py`
- protocol schema and credential-free profile example
- synthetic service, MCP, concurrency, and migration tests
- public operational and design references

Excluded: live catalogs, real prompts or cases, transcripts, credentials, databases, receipts, internal plans/reviews, user-specific adapters, hardcoded paths/session IDs, research scripts, and generated caches.

SkillRanker is reference material only. No SkillRanker source or documentation was copied. See `references/skillranker-ideas.md` for provenance and license cautions.
